# Finance-And-Banking-Analysis-PowerBI

A **Banking and Financial Transaction Analysis Dashboard** created using **Power BI**. The main goal of this project is to provide insights into customer demographics, branch performance, and financial transactions for effective decision-making.

## Dashboard Pages

### 1. Home Page

The Home Page is the landing page of the project.

**Features:**

* Navigation through different dashboards using actionable buttons.
* Provides access to the Customer Insights, Branch Performance, and Financial Transactions & Loans dashboards.

---

### 2. Customer Insights Dashboard

**Objective:**
Analyze customer demographics and account preferences.

**Features:**

* Gender-based customer segmentation:

  * Male
  * Female
  * Other
* Distribution by account types:

  * Savings
  * Fixed Deposit
  * Recurring Deposit
  * Current
* Customer analysis by age group.
* Analysis of customers by top cities.
* Historical customer growth trend from **2000–2025**.

**Use Case:**

* Understand customer preferences.
* Target age-specific or account-type-specific marketing campaigns.

---

### 3. Branch Performance Dashboard

**Objective:**
Evaluate branch-wise performance in terms of customer count, transactions, and balance.

**Features:**

* Branch-wise customer count.
* Branch-wise transaction frequency.
* Total balance managed per branch.
* Average balance per branch.
* Top-performing branches based on:

  * Customers
  * Transactions
  * Account balance
* Interactive map for geographic insights on branch locations.

**Use Case:**

* Identify high-performing branches and regions.
* Support branch expansion and resource optimization decisions.

---

### 4. Financial Transactions & Loans Dashboard

**Objective:**
Analyze financial transaction patterns and loan distribution.

**Features:**

* Transaction segmentation by type:

  * Credit
  * Debit
* Loan distribution by branch.
* Loan distribution by customer over time.
* Historical transaction trends from **2000–2025**.
* Average interest rate.
* Total loan amount.
* Total transaction amount.

**Use Case:**

* Optimize credit/debit transaction strategies.
* Analyze and improve loan disbursement processes.

---

## Key Benefits

* Improved customer targeting based on demographics and account type.
* Enhanced branch performance monitoring and decision-making.
* Better understanding of financial transaction patterns.
* Insights into loan distribution and financial trends.
